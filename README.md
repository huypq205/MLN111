# Cách mạng Tháng Mười Nga 1917 — Kho lưu trữ số

Website giáo dục (Next.js App Router, TypeScript, Tailwind CSS 4). Không có backend, đăng nhập, AI hay 3D.

## Chạy
```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

## Nội dung
Toàn bộ nội dung nằm trong `src/data/` (events, timeline, figures, media, sections, sources), tách khỏi giao diện.
Thêm ảnh: đặt tệp vào `public/images/` rồi thêm `image: { src, alt, credit }` vào mục tương ứng.
Trước khi công bố: kiểm tra lại từng nguồn/liên kết và ghi công ảnh.
